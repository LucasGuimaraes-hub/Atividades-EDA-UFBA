# Problema 3 - Cobertura 5G - Complemento

Código base para o uso da bibloteca *pyGlet* [1] como recurso para a visualização da estrutura de dados e dos elementos do problema.

Como sugestão são fornecidas TADs para manipular cores, pontos e retangulos.
