# Projetos em Python - Estruturas de Dados e Visualização

Este repositório contém projetos práticos desenvolvidos durante a graduação em Engenharia de Controle e Automação na UFBA, focados em resolução de problemas lógicos, manipulação de dados e visualização.

## 📂 Estrutura dos Projetos

* **`/visualizacao-cobertura-5g`**: 
  Simulação e visualização de um problema de cobertura de rede 5G. Utiliza a biblioteca `pyglet` para renderização gráfica e manipulação espacial de pontos e retângulos, aplicando lógica para modelagem de problemas reais.

* **`/validador-placas-mercosul`**: 
  Desenvolvimento de um sistema de validação e processamento de strings baseado nas regras de emplacamento do Mercosul. Foco em tratamento de dados e regras de negócio.

* **`/lab08-listas-pilhas-filas`**: 
  Implementação de Estruturas de Dados fundamentais (Listas, Pilhas e Filas) em Python. Essencial para otimização de algoritmos e manipulação eficiente de informações na memória.

## 🛠️ Tecnologias e Habilidades Aplicadas
* **Linguagem:** Python
* **Habilidades:** Lógica de programação, Tratamento de dados, Orientação a Objetos (TADs), Visualização de dados (pyglet) e Algoritmos de otimização.
